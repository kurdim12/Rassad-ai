## 🟢 الشريحة 3 — Problem

### المشكلة

- 📱 **80% من الأخبار العربية على واتساب وتويتر غير محققة**
- ❌ منصات التحقق الموجودة:
  - ناطقة بالإنجليزية (Snopes, FactCheck.org)
  - أو بطيئة جداً (المراجعة اليدوية تستغرق ساعات)

- 🧠 **تأثير الأخبار الكاذبة العربية:** قرارات صحية خاطئة، فتن طائفية، خسائر مالية

> **لا توجد أداة عربية مفتوحة وفورية للتحقق من الادعاءات اليوم.**

**عناصر بصرية:** إحصائيات + لقطات من ادعاءات منتشرة فعلياً.

## 🟢 الشريحة 5 — Innovation / Tech Approach

### الابتكار: نظام متعدد الوكلاء

بدل نموذج واحد عام، **6 وكلاء متخصصون** يتعاونون:

```
ArabicNLPAgent  →  EvidenceAgent  →  CredibilityAgent
       ↓                  ↓                   ↓
   FakeNewsAgent  →  ClaimTracerAgent  →  VerdictAgent
                              ↓
                       حكم نهائي مدعوم
```

**التقنيات:**

| الطبقة | التقنية |
|---|---|
| 🧠 AI | Google **Gemini 2.0 Flash** + Prompt Engineering عربي |
| 🌐 البحث | Tavily + Serper + DuckDuckGo + Wikipedia (تدرّج تلقائي) |
| ⚙️ Backend | FastAPI + Python 3.11 + Pydantic v2 |
| 💻 Frontend | React 18 + TypeScript + Tailwind (RTL) |
| 🐳 Deploy | Docker Compose · بأمر واحد |

**ما يميّزنا تقنياً:**
- 🎯 **Structured Output** — كل وكيل يُخرج JSON صارم (response_mime_type)
- 🎭 **Demo Mode** — يعمل بدون مفاتيح API (للجنة التحكيم)
- 🛡️ **Source Credibility Scoring** — قائمة معتمدة 25+ مصدر
- ⚡ **Async parallel agents** — تنفيذ متوازي بين الوكلاء حيث أمكن

**عناصر بصرية:** مخطط معماري + شعارات Gemini, FastAPI, React.

## 🟢 الشريحة 6 — Demo (Live)

### عرض حي

**سيناريو الديمو (90 ثانية):**

1. **افتح** `http://localhost:5173`
2. **أدخل**: `«فيتامين سي يعالج فيروس كورونا»` → اضغط «تحقق الآن»
3. **اعرض**:
   - شريط التقدم للوكلاء (مرئي)
   - حكم: **❌ ادعاء كاذب** (ثقة 92%)
   - 3 مصادر موثوقة: WHO + Reuters + مسبار
   - شرح بالعربية يربط الأدلة
   - مسار الوكلاء (مع توقيت كل وكيل بالـ ms)
4. **بدّل** إلى وضع «رابط» وأدخل أي مقال خبري
5. **بدّل** إلى وضع «صورة» وارفع صورة AI → كشف فوري

> 💡 **إن لم يعمل الإنترنت**: الوضع التجريبي يعطي نتائج جاهزة بنفس الجودة.

**عناصر بصرية:** الديمو نفسه (لا screenshot).
